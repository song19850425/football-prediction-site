Phase 1: 基础能力升级（高价值·低门槛）

高影响 低-中成本
🧠 引入XGBoost替代手工权重
来源: FootballGPT / ProphitBet / GoalCast
现状
手工设定各维度权重(泊松40%+单双统计25%+趋势10%+...)，主观性强，难以量化优化
升级方案
用 XGBClassifier 训练胜平负三分类模型，特征包括: 主客队进攻/防守强度、ELO评分、近期状态、主客场胜率、联赛排名差、历史交锋等。模型自动学习特征权重，无需手工设定。
为什么是XGBoost
所有开源项目的一致选择 — 处理表格数据能力最强，解释性优于神经网络，训练快。9个项目中有6个用XGBoost作为主力或核心模型。
输出
胜平负概率分布 + 特征重要性排序(可解释性)

预期收益: 胜平负准确率从手工75%提升至约65-70%(注意: 65-70%是行业水平，手工高准确率可能是过拟合/小样本偏差)。最大价值是可量化、可回测、可持续优化。

📊 时间序列回测系统
来源: ProphitBet / FootballGPT
现状
手工验证单场比赛，样本小、无统计显著性，无法判断模型真实水平
升级方案
实现 TimeSeriesSplit 时间序列交叉验证(避免未来数据泄露)。按赛季/轮次划分训练集和测试集，模拟真实预测场景。输出: 赛季准确率、盈亏曲线、胜率、ROI、最大回撤等指标。
核心原则
禁止用未来数据训练 — 只能用比赛前已有的数据(前N轮)预测下一轮。这是ProphitBet强调的关键原则。

预期收益: 从"感觉对"到"数据说话"。有了回测系统，每次模型改动都能量化评估是否有效(类似FootballGPT的公开ROI追踪)。这是模型迭代的基础设施。

💰 价值投注计算(赔率对比)
来源: MatchPredict / FootballGPT
现状
只输出预测概率，不与赔率对比，无法判断是否有投注价值
升级方案
引入赔率数据，计算: 隐含概率 = 1 / 赔率 → Edge = 模型概率 - 隐含概率。当 Edge > 5% 时标记为"价值投注"。参考FootballGPT: 仅推Edge>6%的场次，这是长期盈利的关键。
延伸功能
串关组合计算 — 多场联合概率 vs 联合赔率，找正期望值串关(MatchPredict已有此功能)

预期收益: 从"猜对错"升级为"找价值"。博彩长期盈利靠的不是高胜率，而是找到被市场低估的场次。此功能直接对接实战应用。

📦 统一数据源 + 历史数据库
来源: ProphitBet (football-data.co.uk)
现状
WebSearch零散抓取，数据不统一，无历史库，每次从零开始
升级方案
接入 football-data.co.uk CSV 数据(ProphitBet使用的数据源)，覆盖英超/西甲/意甲/德甲/法甲/英冠等联赛，包含: 赛果、赔率(B365/平均赔率)、射门/射正/角球/黄牌/红牌等。建立本地SQLite数据库，定时同步。
数据字段
主客队、比分、半场比分、射门、射正、角球、黄牌、红牌、B365胜平负赔率、大小球赔率等20+字段

预期收益: 所有分析的基础。有了历史数据才能训练模型、做回测、计算特征。这是最优先的基础设施工作。

Phase 2: 特征与模型深化（中价值·中门槛）

高影响 中成本
⚡ 特征工程升级(20+特征)
来源: FootballGPT / GoalCast FC
现状
仅8-10个基础特征(进攻/防守强度、主场优势、单双率等)
升级方案
从football-data数据衍生20+特征，参考FootballGPT和GoalCast FC的特征体系:
进攻类
场均进球、场均射门、场均射正、射正率、进球效率(进球/射正)
防守类
场均失球、场均被射门、场均被射正、零封率、失球效率
状态类
近5场胜率、近5场场均进球、近5场场均失球、状态衰减加权(越近权重越高) — FootballGPT form decay
赛程类
休息天数、连续客场次数、赛程密集度 — FootballGPT fatigue
交锋类
历史交锋胜率、近3次交锋结果、主场交锋胜率
联赛类
排名差、积分差、主客场联赛排名

预期收益: 特征是模型上限的决定因素。从10个特征扩展到25+，预计准确率提升5-10%。XGBoost能自动学习各特征的重要性，无需手工调权重。

🔗 Poisson + XGBoost 加权集成
来源: ai-football / TheDrawCode
现状
纯Poisson模型，对非线性关系(如球队风格克制)捕捉能力有限
升级方案
两路模型集成:
Poisson路: 基于攻防强度的概率分布(优势: 比分分布可解释，有理论基础)
XGBoost路: 基于20+特征的机器学习分类(优势: 捕捉非线性模式)
按权重融合胜平负概率，初始权重 Poisson 40% + XGBoost 60%，通过回测优化最优权重。
比分生成
保留Poisson的比分分布矩阵，但用XGBoost的胜平负概率做Bayesian校准(FootballGPT的思路)，修正分布。

预期收益: 集成模型通常比单模型提升3-5%准确率。ai-football的三模型(XGB+Poisson+LLM)思路就是这个道理 — 不同模型捕捉不同模式，融合后更稳健。

🔍 Boruta自动特征选择
来源: ProphitBet
现状
手工选择特征，可能遗漏重要特征或保留噪声特征
升级方案
引入 Boruta算法(ProphitBet内置功能): 通过随机森林迭代，将每个特征与"影子特征"(随机打乱)比较，统计显著性判断特征是否真的有预测力。自动筛选有效特征，减少人工调参。
配合工具
特征重要性排序、相关性矩阵、方差分析 — 全部从ProphitBet的分析工具借鉴

预期收益: 减少过拟合(剔除噪声特征)，提升模型泛化能力。同时提供可解释性 — 知道哪些因素最重要。

🤝 平局预测专项优化
来源: TheDrawCode
现状
平局是三分类中最难的(样本最少，约25%)，模型倾向于预测主胜/客胜，平局召回率低
升级方案
借鉴TheDrawCode专攻平局的思路:
1. 类别权重调整: 平局类权重×1.5，让模型更关注平局样本
2. 阈值优化: 不使用默认0.33阈值，通过验证集搜索最优平局阈值(如0.28)
3. 平局特征工程: 两队防守强度乘积、近5场平局率、历史交锋平局率等专门特征

预期收益: 平局预测准确率提升5-10%。平局赔率通常较高(2.5-3.5)，即使命中率略低，价值投注空间也很大。TheDrawCode专攻平局就是因为这个原因。

🎯 Kelly准则仓位管理
来源: FootballGPT
现状
无资金管理概念，只给预测不给仓位建议
升级方案
实现 Kelly Criterion:
f = (b × p - q) / b，其中 f=仓位比例，b=赔率-1，p=获胜概率，q=输的概率
FootballGPT使用: 最大2-3%仓位/场，高选择性(每周仅选少数场次)。实战中用Kelly的一半(Half-Kelly)更稳健。
输出
每场预测附带"建议仓位"百分比，高置信度场次仓位高，低置信度场次仓位低

预期收益: 从"预测对错"升级为"资金管理"。长期盈利靠的是正期望值 + 合理仓位。Kelly准则是博彩/投资的黄金标准。

Phase 3: 前沿探索（高价值·高门槛）

中-高影响 高成本
🧬 LSTM时序模型集成
来源: FootballGPT
现状
无深度学习模型
升级方案
引入 LSTM神经网络 捕捉球队状态的时间序列模式。输入: 近10场比赛的时间序列特征(进球、失球、射门等)，输出: 下一场表现预测。与XGBoost+Poisson集成，形成三路融合。
注意
需谨慎 — 深度学习需要大量数据(50万+事件才有意义)，小样本下XGBoost通常优于LSTM。参考Deep-Learning-Football项目: 3层NN仅53%准确率。

预期收益: 数据量足够时提升2-5%。更重要的是捕捉XGBoost无法捕捉的序列模式(如连续不胜后的反弹、连胜后的回落)。

💬 LLM智能分析文本生成
来源: MatchPredict / ai-football
现状
分析文本为手工模板生成，缺乏"分析感"
升级方案
接入LLM(GPT-4o/DeepSeek)，将模型输出(概率、比分、特征重要性) + 球队近期数据 + 赔率信息结构化喂给LLM，生成自然语言分析报告。 参考ai-football的三阶段: XGBoost算概率 → Poisson生比分 → LLM写分析。
关键约束
LLM只做文本生成，不做概率计算 — 概率由统计/ML模型输出，LLM负责"翻译"成人话。这是MatchPredict和ai-football的共同设计原则。

预期收益: 体验升级。预测结果从干巴巴的数字变成有逻辑的分析文字，用户体验大幅提升。同时可生成多语言、多风格的分析内容。

🎲 扩展预测维度(半全场/角球/黄牌)
来源: MatchPredict
现状
胜平负+比分+大小球+单双(4维)
升级方案
新增预测维度:
1. 半全场(9种组合): 半场泊松模型 + 全场泊松模型联合概率(MatchPredict已有)
2. 角球大小: 基于场均角球数据的泊松分布
3. 黄牌大小: 基于场均黄牌数据的泊松分布
football-data.co.uk数据已包含角球和黄牌字段，无需额外数据源。

预期收益: 差异化竞争优势。90%的开源项目只做胜平负。覆盖亚洲盘口更多玩法，实用性更强。

🖥️ Streamlit交互式仪表盘
来源: GoalCast FC / Goal-Prediction
现状
静态HTML报告，无交互，需手动生成
升级方案
构建 Streamlit Web应用:
- 每日比赛预测面板
- 模型回测结果可视化
- 特征重要性分析
- 联赛积分榜/状态追踪
- 赔率变动监控
GoalCast FC和Goal-Prediction-Model都用Streamlit作为UI，开发成本低，效果好。

预期收益: 从"一次性报告"变为"可交互工具"。用户可自主选择联赛、比赛、调整参数、查看历史。

Boruta特征选择 → 25+高级特征 → 平局专项优化(权重+阈值) → 单双/大小球ML化

LLM分析文本生成 → Streamlit仪表盘 → 回测可视化 → 半全场/角球扩展
Step 5: LSTM探索 + 持续优化 (长期)
LSTM时序模型集成 → 多联赛扩展 → 模型持续迭代 → ROI追踪系统

最值得优先做的3件事

1. 建立数据源 + 回测框架 — 这是一切的基础。没有历史数据和回测，模型好坏全靠感觉。football-data.co.uk免费且覆盖全面，优先搞定。

2. 引入XGBoost替代手工权重 — 9个项目6个选XGBoost不是巧合。它处理表格数据最强，训练快，可解释。从手工权重→ML模型是质变。

3. 价值投注 + Kelly仓位 — 从"猜对错"升级为"找价值"。长期盈利靠的是正期望值+合理仓位，而非高胜率。这是从娱乐到实战的关键跨越。
