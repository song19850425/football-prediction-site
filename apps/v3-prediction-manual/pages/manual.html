V3.0 2026年8月 · 正式版 · 文档版本 1.0
01 / 概述

V3.0 核心改动

架构升级

从 V2.x 的单模型架构升级为多模型融合架构，支持 Stacking、Blending、Voting 三种集成策略，显著提升预测稳定性和准确率。

因子系统重构

新增场外因子（Off-Field Factors）模块，覆盖天气、裁判、伤病、赛程密度、球队状态等 5 大类 30+ 指标，为模型提供更丰富的决策维度。

特征工程增强

引入时间序列交叉验证（TimeSeriesSplit），防止数据泄露；新增滚动窗口特征（Rolling Window Features），捕捉近期状态趋势，使模型对短期波动更敏感。

模型升级

新增 XGBoost、LightGBM、CatBoost 三大梯度提升模型，与原有逻辑回归形成互补，覆盖线性与非线性、浅层与深层多种建模路径。

预测输出升级

从单一胜平负预测扩展为胜平负 + 大小球 + 单双 + 比分四维预测，满足不同投注策略需求，提供更全面的决策支持。

回测系统

新增完整的回测框架，支持历史数据滚动验证、策略收益评估、夏普比率（Sharpe Ratio）计算，为策略优化提供量化依据。

02 / 架构

预测框架

V3.0 预测系统采用分层流水线架构，从数据采集到最终输出形成完整闭环。各层职责清晰、边界明确，支持灵活扩展和独立优化。

流水线特性

  • 数据采集层：多源数据接入，涵盖历史赛果、赔率数据、球队/球员统计、场外因子等维度，支持实时和批量两种模式。
  • 特征工程层：时间窗口特征构建、特征交叉组合、缺失值智能填充、特征标准化，确保模型输入质量。
  • 模型训练层：基学习器（LR、XGBoost、LightGBM、CatBoost）并行训练，元学习器（Stacking/Blending）融合基学习器输出。
  • 预测推理层：多模型并行预测，概率校准（Platt Scaling / Isotonic Regression），集成融合输出最终概率。
  • 输出层：生成四维预测结果 + 置信度评分 + 三类推荐策略，支持 API 和可视化两种交付方式。
03 / 算法

核心算法

V3.0 采用梯度提升树 + 逻辑回归的混合模型架构，通过 Stacking 集成策略将多个基学习器的预测结果融合，实现更优的泛化性能。

XGBoost 梯度提升决策树

采用正则化目标函数，内置 L1/L2 正则项防止过拟合。支持特征重要性排序，可输出各特征对预测的贡献度。通过二阶泰勒展开近似损失函数，训练效率高。

LightGBM 基于直方图的提升

基于直方图算法加速训练，采用 Leaf-wise 生长策略（按叶子分裂增益最大方向生长），减少无效分裂。原生支持类别特征（Categorical Features），无需 One-Hot 编码。

CatBoost 有序提升

采用 Ordered Boosting 策略处理梯度估计偏差，使用对称树结构加速推理。自动处理类别特征，内置交叉验证避免过拟合，对超参数相对不敏感。

Stacking 集成融合

第一层：基学习器（LR、XGBoost、LightGBM、CatBoost）分别产出预测概率。第二层：元学习器（逻辑回归 LR）融合各基学习器输出，学习最优加权组合。

概率校准

采用 Platt Scaling（基于逻辑回归对原始预测概率进行校准）和 Isotonic Regression（保序回归，不假设校准曲线形状）两种方法，确保模型输出的预测概率与实际发生频率一致，为后续策略计算提供可靠的概率基础。

04 / 因子

场外因子系统

场外因子系统是 V3.0 的核心创新模块，从天气、裁判、伤病、赛程、状态五个维度构建指标体系，为模型提供超越传统数据的决策信息。

因子类别 指标数量 典型指标 更新频率

裁判因子 5 场均黄牌、场均红牌、主队胜率、场均点球、执法历史 赛季更新

共计 5 大类 32 项指标，覆盖赛前至赛后的全周期数据采集。各因子均经过标准化处理和缺失值填充，确保模型输入的完整性和一致性。

05 / 输出

预测输出

V3.0 提供四维预测输出，涵盖胜平负、大小球、单双、比分四大维度，配合置信度评分和策略推荐，为不同风险偏好的用户提供差异化决策支持。

维度 1

胜平负预测

输出主胜 / 平局 / 客胜三项概率分布，并标注推荐方向。概率之和为 100%，经 Platt Scaling 校准。

维度 2

大小球预测

输出大球 / 小球两项概率，结合常用盘口（2.5/3.5 球）给出推荐选择。考虑球队攻防风格和近期进球趋势。

维度 3

单双预测

输出总进球数为单数 / 双数的概率分布，基于历史单双分布和球队进球特征的统计建模。

维度 4

比分预测

输出最可能比分 Top-3 及对应概率，基于泊松分布模型和攻防实力参数估算，覆盖主流比分范围。

置信度评分

A 级 · 高置信度 ≥ 75% B 级 · 中高置信度 60-75% C 级 · 中置信度 45-60% D 级 · 低置信度 < 45%

置信度基于模型集成一致性、历史回测准确率和特征完整度综合评定，A 级为最高置信等级。
